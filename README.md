---

## 🏛 Architecture & Philosophy

- **Zero-Dependency Static Architecture**: Pure **HTML5**, **CSS3**, and **Vanilla JavaScript (ES6+)**.
- **No Build Step Required**: Zero bundlers (no Vite, Webpack, Tailwind CLI, or npm runtime dependencies).
- **GitHub Pages Native**: Strictly relative asset paths and GitHub Actions workflow support for instantaneous deployment at `https://premb2907.github.io/Portfolio-Hub/`.

## 🚀 GitHub Pages Deployment

1. Go to your repository on GitHub: **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**: Select **Deploy from a branch** (or **GitHub Actions**).
3. Branch: `main` and folder `/(root)`.
4. Live site: **[https://premb2907.github.io/Portfolio-Hub/](https://premb2907.github.io/Portfolio-Hub/)**
