## 🏛 Architecture & Philosophy

- **Zero-Dependency Static Architecture**: Pure **HTML5**, **CSS3**, and **Vanilla JavaScript (ES6+)**.
- **No Build Step Required**: Zero bundlers (no Vite, Webpack, Tailwind CLI, or npm runtime dependencies). Fast first-paint times and ultra-lightweight asset footprint.
- **Vercel Optimized**: Ready for instantaneous zero-config deployment by connecting the GitHub repository to [Vercel](https://vercel.com).
- **Design Aesthetic**: Inspired by Swiss editorial layouts, Awwwards winners, modern brutalism, and typography-first minimalism.

## 🚀 How to Deploy to Vercel

1. **Import Repository**:
   - Go to [vercel.com/new](https://vercel.com/new) and log in.
   - Choose the GitHub repository `PremB2907/Portfolio-Hub`.
2. **Framework Preset**:
   - Select **Other** (since this is a pure static HTML/CSS/JS site).
   - Build Command: Leave blank / none.
   - Output Directory: Leave blank / root (`.`).
3. **Deploy**:
   - Click **Deploy**. Vercel will serve `index.html` and all static assets globally via edge CDNs.
